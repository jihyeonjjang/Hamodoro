# Hamodoro (햄모도로)

메뉴바에서 햄스터와 함께 집중하는 macOS 뽀모도로 타이머 앱입니다.

## 소개

메뉴바에서 직관적으로 볼 수 있는 뽀모도로 타이머예요. 집중 중엔 쳇바퀴를 타고, 휴식 중엔 커피를 마시는 햄스터가 메뉴바에서 지금 상태를 알려줍니다.

## 주요 기능

- 🐹 메뉴바 애니메이션 아이콘 (대기 / 일시정지 / 집중 / 휴식)
- ⏱️ 집중·휴식 시간과 반복 사이클 수 설정
- 📊 새벽 6시를 기준으로, 오늘의 누적 공부 시간 기록
- 🔔 집중/휴식 시작 알림 (개별 on/off 가능)
